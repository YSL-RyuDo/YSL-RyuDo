### 게임 서버 프로그래머 · 석사과정

플레이어, 경기, 게임 데이터를 연결하는 시스템을 만듭니다. C++ 게임 서버와 Unity 멀티플레이 연동을 개발하고, 개발 중 마주친 질문을 실험과 연구로 이어갑니다.

현재 **홍익대학교 세종캠퍼스 게임학과(공학) 석사과정**입니다. 학부연구생과 2025년 오투큐브 소프트팀장으로 개발·연구·지식 공유를 이어왔습니다.
