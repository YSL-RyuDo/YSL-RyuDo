## 主な開発

| プロジェクト | 担当内容 | 公開範囲 |
|---|---|---|
| Project Vector | C++サーバー、ゲーム通信、試合ライフサイクル・再接続連携。開発継続中 | ソース非公開 |
| [BNB / BnBServer](https://github.com/YSL-RyuDo/BNB) | マルチプレイヤー連携、報酬・ショップ、CISC-W価格研究の出発点 | 公開 |
| [DeathGuider](https://github.com/YSL-RyuDo/DeathGuider) | チーム担当：経営・施設・訓練・戦闘準備 | 原本を明示したポートフォリオフォーク |
| GCTLAB | アップロード検証、ストレージ連携、再試行・永続化、運用フローの共同開発 | 非公開の共同開発、概要のみ |

Magicwar、DumbGuys、Cylinder、RE:BOUND、Moonlit Hotel、PitchLabにも取り組みました。アクセス可能なリポジトリで詳細な貢献を確認できます。リポジトリ所有はチームコード・外部素材の全体を単独制作したことを意味しません。
