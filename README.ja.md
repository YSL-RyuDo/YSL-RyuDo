### ゲームサーバープログラマー · 修士課程

プレイヤー、試合、ゲームデータをつなぐシステムを開発しています。C++ゲームサーバーとUnityのマルチプレイヤー連携に取り組み、開発中の疑問を実験と研究につなげています。

現在、**弘益大学校 世宗キャンパス ゲーム学科（工学）の修士課程**に在籍しています。学部研究生と2025年O2CUBEソフトウェアチームリーダーとして開発・研究・知識共有に取り組みました。
